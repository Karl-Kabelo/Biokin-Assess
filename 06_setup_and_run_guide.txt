BIOKIN ASSESS MVP - SETUP AND RUN GUIDE

Suggested folder structure:

biokin-assess/
  frontend/
    index.html
  backend/
    server.js
    package.json
    .env

1. Front end

- Copy the contents of 02_frontend_mvp_index_html.txt.
- Paste into a file called index.html.
- Open it using VS Code Live Server or another local static server.
- If using Live Server, the common URL is:
  http://localhost:5500

2. Backend

Create the backend folder:

mkdir biokin-backend
cd biokin-backend
npm init -y

Install dependencies:

npm install express better-sqlite3 bcryptjs jsonwebtoken zod cors helmet express-rate-limit dotenv
npm install --save-dev nodemon

Then:

- Copy the contents of 03_backend_server_js.txt into server.js.
- Copy the contents of 04_package_json.txt into package.json.
- Copy the contents of 05_env_example.txt into a file called .env.
- Change JWT_SECRET before any serious testing.

Run:

npm run dev

Backend should run on:

http://localhost:4000
